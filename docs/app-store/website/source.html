Build and modify

Use an Apple silicon Mac with macOS 14 or later, compatible Xcode tools (the release used Xcode 27.0), and CMake. Read BUILD.txt and the included source documentation after extraction.

tar -xzf PulseCanvas-1.0.0-2-source.tar.gz
cd PulseCanvas-source
./scripts/build-projectm.sh

To modify ProjectM, edit the extracted library under .build/projectm/source/, then run the engine build script again. Rebuild and sign the entire local application, including its nested library, with your own identity. The snapshot's store-release.sh test command uses the project's internal team default. For your own Xcode build, use this command instead, substituting your own Apple team and a bundle identifier you control:

xcodebuild -project PulseCanvas.xcodeproj -scheme PulseCanvas \
  -configuration Release -derivedDataPath .build/local-source-test \
  PRODUCT_BUNDLE_IDENTIFIER=com.example.pulsecanvas.local \
  CODE_SIGN_IDENTITY="Apple Development" CODE_SIGN_STYLE=Manual \
  DEVELOPMENT_TEAM=YOUR_APPLE_TEAM_ID build

Replacing a library inside the original signed App Store application does not preserve its signature. The source allows you to rebuild a complete local application; keep library validation enabled. No Protomota signing credentials are needed or provided.
