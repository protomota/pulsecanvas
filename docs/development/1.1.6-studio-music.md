## Use

- iPhone/iPad: Project actions (…) → Choose music.
- Mac: Add soundtrack / Replace audio → Choose music. Choosing an audio file
  remains available in that menu.
- Vision Pro: Studio's bottom toolbar → Choose music. Import audio remains.

The picker loads the complete catalog behind the selected Radio library, with
All songs, Favorites and title/genre search. Favorites use existing Radio song
hearts. An empty favorites filter shows an explanation and keeps All songs
available. This is a Studio selection action, not a Radio playback action.
Browsing does not start Radio or change its station. Cancel stops a pending
download/preparation before Studio commits the new soundtrack.

Selecting a song reuses Radio's verified audio cache, then makes a permanent
Studio-owned copy. The selected title appears in Studio, a new beat-aligned
timeline is generated, and normal project saving and MP4 export apply. Radio
cache cleanup therefore cannot delete an imported Studio soundtrack. Download
and analysis errors are shown in the picker; those steps happen before replacing
the current soundtrack. Existing user-file import remains supported.

No export restriction is added for these songs. Existing license information,
server catalogs, original song files and Radio favorites are unchanged. Favorites
filter the songs present in the currently loaded library. Portable project files
still contain references, not embedded audio; another device may need the song
located again, as with existing imported soundtracks.
