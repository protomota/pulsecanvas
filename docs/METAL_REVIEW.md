Do not treat the HTML page’s saved choices, star/heart icons, or CSV scores as replacements for the red-label policy unless Brad changes the process. Do not automatically prune while he is rating.

Read `metal-keeper-selection.json` for permanent IDs, exact Finder tag evidence, replacements and deleted implementation functions. No user soundtrack, saved project, live session or existing review video/tag is rewritten.

Future application of this policy should re-read actual Finder tags, preserve the review folder, and validate all offered GPU passes, migration, Studio switching and decoded exports. Do not renumber existing IDs, commit, push, install a release or change distribution channels without the user’s authorization.
