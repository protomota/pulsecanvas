# PulseCanvas Studio 1.1.5 (23)

Released for Mac testing on 2026-10-18. Both binaries were built from
[`4be81e169b6a7c712585b64aed2f434caa823895`](https://github.com/protomota/pulsecanvas/commit/4be81e169b6a7c712585b64aed2f434caa823895).
Unfinished iPhone, iPad and Vision Pro targets were excluded from this Mac snapshot.

## Radio is server driven

The app loads its station labels and catalog links from
<https://radio.pulsecanvas.si/stations.json>. Each linked station catalog supplies
its song metadata and audio paths. Neither Mac edition embeds a station directory
or song catalog, and the Swift app has no hardcoded list of genre stations.
`radio/station-names.json` is a publishing template, not an app resource.

The live directory has eight choices including All Music, covering all 15 songs.
Its SHA-256 at release was
`bac6aacec4039eec3ac1acca3beeacd8c07be8796408d43db5efe40c970b0894`.
Station names and membership can change in R2 without an app release. Leave Radio
and reopen it to refresh an already loaded directory. See [Radio stations](../RADIO_STATIONS.md).

## Verification

Passed on the frozen source and actual generated artifacts:

- Store edition regression suite: 336 native identities; 2,016 offline GPU checks;
  deterministic rendering, percussion response, seeks and frame rates; all 336
  respond to beats above zero Chaos and ignore audio at zero Chaos while retaining
  procedural motion in wide/portrait at three zoom speeds.
- Radio regressions: station persistence, shared visualizer filters, favorites,
  track transitions, skipped tracks, catalog refresh, shutdown and failure handling.
- Provenance: 20 regression tests; 7,766 bundled community presets, 67 texture images,
  and all 141 presets with additional notice candidates retained. App and matching
  source-archive resources checked.
- Expanded Store distribution package: arm64, sandbox, 336 native effects, zero
  community presets, no projectM/OpenGL or Sparkle; Apple archive validation and
  upload succeeded.
- Real mounted Creators DMG: signed application bytes and layout match; notarization,
  stapling, Gatekeeper and pinned Sparkle signature passed.
- Real Sparkle fixture probes: newer version available, current version unchanged,
  disabled automatic checks send no request. No update was installed into a user's app.
- Website: six installer-metadata tests; all 19 media files and ten downloads
  range-readable in R2; build and 11-page SEO checks passed. Browser inspection
  confirmed the live 1.1.5 download/source links and appcast enclosure.

A clean-machine manual installation and an end-to-end production Sparkle install
were not run. The user's installed app, soundtrack, preferences and favorites were
not replaced during release verification. Existing application, engine, preset and
texture licensing distinctions and unresolved permissions remain documented in
[distribution guidance](../DISTRIBUTION.md) and the bundled provenance notices;
this release does not assert clearance of community asset rights.
