# Native Mac App Store marketing screenshots

Three Apple-supported 1440 × 900 opaque RGB JPEGs for PulseCanvas Studio 1.0.3 (13). Every embedded screenshot is an actual capture of the isolated **STORE_BUILD** app with **240 native Metal visualizers**. No Creators interface, projectM preset, external texture, or Creators effect count is used.

1. `01-music-in-motion.jpg` — music response and 240 native Metal visualizers.
2. `02-build-your-studio.jpg` — beat-aligned Studio scenes with individual bar lengths.
3. `03-create-and-export.jpg` — MP4 with audio, wide/phone/square formats and up to 4K60; completely free.

The complete app capture remains visible in each slide, scaled uniformly from 1440 × 900 to 1080 × 675. Typography, the real app icon, and subtle CSS lighting sit outside the capture. The original source captures remain unchanged in `../native-1.0.3-13/`; their capture provenance is documented in that folder's manifest. SHA-256 hashes, dimensions and source mapping are in `manifest.json`.

`layouts.html` is the reproducible HTML/CSS design source. Serve the repository's `assets/` folder locally, navigate to the HTML file with `#music`, `#studio`, or `#export`, and capture the upper-left 1440 × 900 rectangle with browser screenshot tooling. `#overview` displays a 1440 × 300 contact sheet. The captured JPEGs are the upload masters.
